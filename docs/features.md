# Features

What works on a Reflipped server today, in plain words. A part of the game that isn't supported yet shows an **H404** error; please [report it](https://github.com/torkd/reflipped/issues).

## Getting started
- **A ready-made Reflipped app** on the project's Releases page: it holds none of the game's files and takes them, once, from the original app installed on the phone or from your copy of its APK file. You can still build the app yourself ([building the Reflipped app](building-the-app.md)).
- **Local play** on Android 7 and newer: the Reflipped app runs the server on the phone, so one player can play alone. It gets the game's data once from an online Reflipped server that offers it (or from a saved file), and the game files stay when moving between Local play and a server with the same game data, even when one of them uses mods or a translation. In Local play, **Account Info → Admin panel** opens the phone's own admin site, without a password: events, the clock and settings, and the save to download or replace.
- The full first-time download of the game's data, straight from the server. It keeps going when you switch to another app or turn the screen off, with its progress in a notification (Android 13 and newer ask once whether the app may show notifications).
- Switching servers without downloading the game data again: when the last server used mods or a translation, the app puts back the few files they changed (a few MB), as long as the new server offers that. Otherwise it warns that the data will be downloaded again.
- Installing the game data from a game data pack file instead of downloading it, on any server ([Game data packs](game-data-pack.md)), and exporting the game data from a phone as a pack, to install it on another phone without a computer. A server owner can run a server without the game data: its players install a pack, and the server sends only its own extras.
- The stamina reminder: a phone notification when your stamina is full, switched on or off in **Game Settings → Notification Settings**.
- **My servers**: one list with the included community servers and the ones you add yourself, each with its name, description, picture and event mode.
- The tutorial.
- The in-game news page: server owners write their own posts in the admin website, and the server also announces every event, summoning portal and boosted-drops week one week before it opens (in Classic, Accelerated and Manual mode, switchable by the owner), listing what can be obtained from it. The page shows ten posts at a time.
- App and server versions: the title screen shows the Reflipped app's version and the server's, each new app version installs as an update over the last, and a server owner can set the oldest app version the server supports, so an older app says it needs an update instead of failing later. A server can also announce a newer app without requiring it: the app shows "Update available" once, with a link to the owner's update page. The admin site shows which app each player last used. When the owner offers the new app's file, apps they built can also install it from that notice, with Android's own confirmation.

## Accounts
- Player accounts on the server's website (`/portal` at the server's address): sign up, log in, change your password and turn on two-step login with an authenticator app.
- Logging in from the Reflipped app: your account keeps your save, so a new phone or a reinstall picks it up again. Your save plays on one phone at a time. Guest play still works; Sign out in Account Info returns to the account and server choices while keeping the same server's downloaded data.
- Linking a phone that plays without an account (also the original app) to your account: get a short code on the website and type it in the game as your profile comment. If your account has no save yet, that phone's progress becomes your save.
- Lost or sold phone: unlink it from your account on the website (with your password). Its game stops, your save stays, and you can play it on another phone.
- Deleting your save: on the website (with your password), or from the game's own account menu in the original app. Your account and its login stay and the game starts a new save; the server keeps a copy for 30 days, which the server admin can bring back from the admin website.
- Your player on the website: see your name, rank, beads and mana, download your own save and, when the server's owner allows it, import one (for example from Local play or another server), and see which mods the server uses. In Time Travel mode, choose a historical period to play an earlier event again, without changing the date for anyone else.

## Units and armaments
- Unit levels, uncaps (over-limit), evolution, mana boards, EX boosts, Amity Scrolls and character stories; "Uncap All", "Convert All to EXP" and locking units.
- Second mana boards come out over time: as the event timeline plays, each unit's second board arrives when it did in the original game, for every player of the server at once. Progress on a board stays saved if the timeline is moved back before it.
- Unit buffs arrive over time too: as the timeline plays, about 130 units get their stronger abilities, leader skills, stats and skill gauges in eight steps, and 57 armaments their stronger or added abilities in one, at the points where the original game made them, instead of having them from the start. (Reworked abilities and skills whose earlier versions aren't known keep their final form.)
- Selling items for mana from the item list.
- Armaments: upgrading, awakening, selling, melting and locking, one at a time or all at once ("Awaken All", "Melt Down All"). An armament that is in a party can't be melted down, only its duplicates. Ability cores and Wrightpieces past what a player may hold turn into mana, as in the original game.
- Augmenting armaments: the augment shop raises 26 armaments past their usual maximum, step by step, for gears and other materials (from player rank 90). An augmented armament can't be melted down, only its duplicates, so the augmentation is never lost.
- Parties and party groups, including Seconds and Ability Cores. Party codes: show a party's code and other players can enter it to copy the party with their own units.
- The encyclopedia, with read entries remembered for each player.
- Shroombo joins when you tap it in the town after main quest 1-8-4.

## Quests and battles
- Every main story quest.
- Character quests, EX quests and the Kaleidoscope dailies.
- Solo boss battles.
- Many event quests: rush events, ranking events (ranked against the other players on the server, with rank rewards in the gift box when the results come out), story events and World Story events with their bosses.
- The Haunt: the monthly 30-floor tower, with its monthly reset and the skip to floor 16 for players who reached floor 18.
- Solo Boss Challenges and Nostalgia Trials: two clears a day, spent only when you win, from player rank 80 (90 for the Nostalgia Trials), with the bonus chest of a quest's first S+ clear.
- Attempt limits on other quests: world story Solo Boss Challenges (one clear a day), anniversary and event-day quests (one clear), and Chrono Trials (ten starts a day, unlocked by the six Hell Solo Boss Challenges, with border rewards for clear times sent to the gift box).
- Practice Combat: the Lignoid fights cost no stamina, their first clears bring the practice armaments and an S+ clear its title, and Battle History keeps your last 50 practice battles. Skill previews play too.
- The Necropolis: Door to the Depths after main World 4, then three Depths quests in each element, the harder Depths and the Beast of the Abyss bosses, each of which uses up an item on a win.
- The Treasure Zone: six element quests after main quest 1-8-4, each clear using a Golden Skull (10 a month at the Trading Post); quests that need an item to unlock use it on their first clear.
- Scouting and Dream Armament Selection seasons: trade the season's ticket for a unit or armament of your choice. As in the original, the paid seasons sell their ticket bundle once per season (for any beads, free ones first) and the ticket gift promos mail their ticket to everyone at their first login during the season. Your server admin can make any season, or the Start Dash bundle, free or paid instead, and can also mail tickets.
- The Start Dash bundle for new players, whatever the server's date: during your first 7 days, buy it for beads (any kind) and trade its ticket for a 4- or 5-star unit of your choice; it also comes with a 10-Pull Summoning Ticket and 20 Star Slivers.
- Costs that took paid beads only in the original game (the portals' daily discounted pull, the season ticket bundles, the Bundle Marketplace) take any beads in the Reflipped app, free ones first.
- The Bundle Marketplace in the Shop: the Beginner's, Staminade, Unit Upgrade and monthly Ether and Element bundles, for beads.
- Periodic packs: a server owner can give every player the original's Monthly, 90-Day Monthly, Staminade Monthly and Rank Achievement packs, delivered to the gift box (see [login rewards](login-rewards.md#periodic-packs)).
- Lineup choices: in the co-op challenge seasons' Boss Coin shop and the Beast of the Abyss shop, you pick one armament lineup, once, and the shop sells you that lineup.
- The Trove: your own lineup of 8 products each day, some at a discount, changing at the daily reset.
- Score Scramble: a battle that runs to its end scores; score borders pay the event's coins once each through the gift box, and the event keeps your recent battles (a wiped-out one is listed as retired, with no score). Its quests need one file from the Chinese version's game data, which the server can send ([game assets](cdn-download.md#chinese-game-data-optional-for-score-scramble)).
- The Hanifolk Carnival: three bosses with their own party sets (no unit in two of them), scores from difficulty and clear time, each boss's best kept, and total score rewards through the gift box.
- Raid events (Sagas of Conquest): one boss for the whole server, with its HP sized for your server's players (an admin setting), tally rewards for every boss defeated, rankings by clears per difficulty with their rewards, and the raid's own party sets.
- Suggested parties: the button under a battle lists the parties other players on the server last cleared it with, newest first, and you can copy one, with each party's power as it was when it won.
- Stamina: battles cost it (less during stamina campaigns), giving up gives it back, it refills over time, a rank-up adds a full bar, and beads and stamina potions top it up.
- Boost seasons, such as the Material Gathering Season and the 2× drop weeks: the quests they cover pay 1.5× or 2× drops, EXP or mana while they run, with the boost badges showing in the game.

## Co-op
- Hosting a room, with AI companions filling empty slots.
- Joining other players' rooms from the room list or with a room number.
- Recruiting: inviting everyone online through the in-game bell.
- Room links and "Return to Room" after a battle.
- Co-op boss events (The Reckoning: the Steambot fights): their quests, from player rank 120, and a special reward for a win while you have a daily count left (two more each day).
- Co-op challenge seasons: a co-op battle against the boss in the spotlight pays 1.5×, 2× or 3× the Boss Coins, EXP and mana, as the season's schedule says.

## Portals and shops
- Browser pages for portal odds (including guaranteed draws), current events, server help and community links. Their new in-app menu integration still needs a phone check.
- Unit and armament portals at the original game's rates (5% for 5 stars, 7.5% on festival portals), with the exchanges that come with them.
- Star Slivers from portal pulls paid with beads (any kind): 2 a pull, 20 a 10-pull, 2 for the daily discounted pull, 1 a pull on the cheaper armament portals.
- Box gacha, with the last box's reset once you've drawn it empty.
- The Welcome Back Portal for a player back after 60 days or more away, for 3 days from that login, with its Star Sliver Exchange units and armaments; and the Welcome Back Boost: 15 Boss Boosts a day for 7 days.
- Portal tickets: Summoning and Armament Tickets (single and 10-pull), the 4 & 5-Star Portal Ticket (a 4- or 5-star unit), portals' own tickets and the ticket-only portals (such as the 4 & 5-Star and 5-Star Exclusive Portals and the New Year's Grab Bag); the Star Heroes portals' once-per-account 10-pull with a guaranteed 5-star, for any beads; free daily pulls and 10-pulls.
- People's Choice (pick a unit with an exchange ticket; solo choice).
- Portals draw only while they are open, as the app shows them; after a portal closes, its own tickets still work until they expire.
- Most shops, with their purchase and stock limits.
- "How to obtain" on an item or armament: the open boxes and the shops that sell it right now.
- The Star Sliver Exchange: trade Star Slivers for a 4- or 5-star unit or armament you don't have yet, or for Astral Gems, from the exchange's list of the moment.

## Progress and rewards
- Missions: regular, daily, event and Step Up missions, with their rewards; repeatable missions pay every time.
- Treasure hunts: their quests drop the event's item, which counts for the event's missions and buys from its exchange.
- The unit poll: one vote, which counts for its mission.
- Normal and limited-time login calendars, with rewards delivered to the gift box, plus the comeback calendars, anniversary presents and the comeback present for players back after a long break (see [login rewards](login-rewards.md)).
- Titles, earned from title missions and title mail, and set on your profile.
- Following other players: find them by their ID, follow and unfollow, see who follows you and your mutuals, and open their profiles. In co-op you can invite only your mutuals or followers (other players can't find such a room in the list). A guest pays half the stamina, and nothing when joining a mutual's room or from an invitation, and every co-op battle you play to the end with a mutual raises the follow bonus added to your score. Sharing your profile gives a link that opens it in the game and follows you.
- Your profile page: how many units, second mana boards and titles you own, with the counts you choose to show, your favourite units, and a new name whenever you like (up to 20 characters).
- Element drops from quests (orbs and aethers), matching the element of the quest's enemies.
- The gift box (mail) with every kind of gift, including challenge attempts and co-op reward counts, and the Item Log of what you received in the last week. The attempts and counts are kept and refilled every day. Quests with attempts (Solo Boss Challenges, Nostalgia Trials, Chrono Trials and event quests with a daily or one-off limit) spend them, and co-op boss events spend their counts on their special reward.
- Daily resets: Kaleido and Boss Boosts, daily portal pulls and shop stock refresh every game day.

## For server owners
- A saved server name shown in the app, and an in-app Admin panel entry for administrator accounts, protected by the separate admin website's normal login. Save files can be uploaded and downloaded from the in-app Admin panel and the account page.
- An admin website, behind its own login, to look after players: import or download a save (with its gift box and titles), send mail and gifts to one player or to everyone (picking units, armaments, items and titles by name, with rarity and item-type filters), and switch on developer mode for testing (every unit and armament maxed, a stack of every item well under its limit so rewards and shops still work, every quest but the Haunt cleared; a player in developer mode stays off the rankings, raid tallies, rush leaderboard and suggested parties others see).
- Help players who are locked out of their account: set a new password, turn two-step login off, or log them out everywhere. Sign-up can be closed (`PORTAL_REGISTRATION=closed`) so only you create accounts.
- Event schedules independent of the running clock: Classic, Accelerated, Time Travel and Manual, with persistent rotations and a searchable calendar whose "Go to" button jumps the server to any event, or to a later day of it, to test it on its own. Player travel is available in Time Travel mode; admin travel has its own permission. See [events and server rules](events.md).
- Game modes open on their original dates along the event timeline: before the date a mode first opened (the element dailies, the Necropolis, the Haunt, Solo Boss Challenges, Chrono Trials, Score Scramble and others), the app doesn't list it and the server doesn't start it.
- Automatic reward rules by default: original amounts in every mode, and in Accelerated mode an event's progress (its exchange currency, its missions and its limited login calendar) counts the speed, so every event can still be finished. Automatic locks admin gifts and reward edits; Managed rewards have a configurable earning multiplier, and a separate one for bosses.
- A different date for one player, to let them replay a past event while everyone else stays on the server's date.
- Mods: replace game files for every player (see the [modding guide](modding.md)).
- English translation for the units, stories, events and items that were only released in Japanese (see [game assets](cdn-download.md#english-translation)).
- Docker setups with automatic HTTPS, backups and a hardened server for running in public.

The full technical list of server routes is in the [API routes document](routes.md).
