Server clock

Which gacha banners and events are open depends on this date, and so does the season shown in town. By default it starts at a date with content and runs on from there in real time; setting a time restarts it from that time. Start the server with SERVER_TIME=real to follow the real date, or SERVER_CLOCK=frozen to stop the clock (the game's own timers then run slow). Times are in UTC.
