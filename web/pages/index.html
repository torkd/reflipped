Server clock

Which gacha banners and events are open depends on this date, and so does the season shown in town. By default it starts at a date with content and runs in real time on the event calendar, which brings it back to an earlier date before the content runs out (see the Calendar page). Setting a time restarts the clock from that time and stops the calendar; Reset returns to the default. Start the server with SERVER_TIME=real to follow the real date, or SERVER_CLOCK=frozen to stop the clock (the game's own timers then run slow). Times are in UTC.
